WHAT CHANGED IN THIS REVISION

1. The style is now the approved, named block: Paper-Theater Millbrook.
   Each prompt names it AND quotes it verbatim, so the project can resolve
   it by name and the prompt still stands alone if it cannot.

2. Characters are named explicitly. The immutable descriptions carry no
   names by design, so a prompt used to describe a figure without ever
   saying who it was. Every character block now opens with the name.

3. Every prompt lists the canonical reference images to ATTACH, and tells
   the generator the attached image is the authority and the description
   is only a check on it. Text alone will not hold a face across 37
   generations; the reference image is what does that work.

4. Aspect ratios are 3:2 for image pages and 2:1 for chapter openers,
   matching the reader's 2:1 spread of two square pages.

5. Two clauses in the negative block were narrowed because they fought the
   paper style: an unqualified "no drop shadows" forbade the soft contact
   shadows between paper layers, which is how the style builds depth, and
   "no 3D render finish" became "no glossy 3D render finish".

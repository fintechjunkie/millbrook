# The projection booth

Use `loc-projection-booth.png` as the required location reference for `{{LOC:PROJECTION_BOOTH}}`. Preserve the layout, the palette and the paper construction. Locked 2026-08-07; see section 6 of `PATCH_NOTES_FLIPBOOK_ROSTER.md`. One page.

Junie Okafor has kept this running since the Millbrook Auto Vue closed in 1988, for nobody, on Tuesdays and Fridays, "which she will tell you is a hobby and not a sadness." The room had to carry that in its condition alone, and it does: swept floor, film cans squared away on their shelves, the rewind bench in order, the projector maintained. Cared for rather than derelict. **Do not add dust sheets, cobwebs or collapse to any plate set here.**

One addition beyond the block, kept: a clipboard with a ruled sheet hangs on the right-hand wall. It carries no legible writing, so it stays inside the negative block, and a booth log is entirely in character.

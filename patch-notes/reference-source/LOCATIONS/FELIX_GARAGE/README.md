# Felix's garage

Use `loc-felix-garage.png` as the required location reference for `{{LOC:FELIX_GARAGE}}`. Preserve the layout, the palette and the paper construction. Locked 2026-08-07; see section 6 of `PATCH_NOTES_FLIPBOOK_ROSTER.md`. Four pages.

**This room is the only physical proof Felix exists**, and Monke walks Vex and Pip nine blocks to it for exactly that reason. Everything the prose inventories is here: the scarred bench under the window, the pegboard, the coffee can of screws, four bicycle frames in various states of disassembly, the rolling chair with tape on the arm, and the half-built device about the size of a microwave with wire coming out of it and no obvious purpose.

**Two clear spaces were reserved and both arrived.** The blank wall at head height is where THINGS THE DRAGON HAS SET ON FIRE gets taped up crooked, and the empty stretch of bench top is where the round red glasses are folded and set down square. Neither is in the reference and both must be added explicitly by the plate that needs them.

One deviation, harmless: the roof is drawn sound from the inside where the block calls it sagging. The sag is an exterior read and this is an interior.

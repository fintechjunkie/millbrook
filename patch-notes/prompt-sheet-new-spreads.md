# New spreads: image prompt sheet

7 prompts · generated by `node scripts/build-adhoc-prompts.mjs` · do not hand-edit

These are for spreads that are **not in the specs yet**. See
`patch-notes/PLAN-new-spreads.md` for where each one lands and why. Tokens are expanded
through the same code as the four canonical volume sheets, so the style block, the
negative block and every character description here are identical to the ones already
in use.

## Read this before generating

- **The filename is not optional.** The reader resolves images by slug from one flat
  directory, so the name given under each prompt is the only name that will appear in
  the book.
- **The slugs carry letter suffixes on purpose.** Inserting a spread renumbers every
  spread after it, but the image filename comes from the spread’s own `Slug:` field,
  which is independent of the number. So existing spreads keep their original slugs and
  **no delivered artwork is ever renamed.**
- **Two of these have a spoiler condition rather than a clean PASS.** They are marked
  HOLD ONE THING and the condition is specific. Both are things that read fine to us,
  because we know the ending, and would give it away to a first-time reader.
- Warehouse scenes must not come back dark. Roster 6.1a, and the lighting paragraph in
  each prompt says so explicitly.

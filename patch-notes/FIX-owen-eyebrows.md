# FIX — Owen's eyebrows

Three delivered plates show Owen with a bare brow. That is wrong, and it is my error
rather than the spec's. The roster block used to read *a fully bald head with no
eyebrows whatsoever*. Both `MILLBROOK_MAIN_CHARACTER_LOCKS.md` and
`char-owen-canonical.png` give him **strong dark brows**, clearly and unambiguously.

Volume 1 spread 3's very first generation had eyebrows and was **correct**. I read it
as drift against the roster, wrote `NO EYEBROWS AT ALL` into its hard constraints, and
had it regenerated to remove them. The same constraint then propagated to two more
plates.

The roster and all four specs are now corrected, so nothing new will drift. These three
prompts are the repair.

## What to attach

For every one of the three: **`char-owen-canonical.png`**. It is the authority on the
brows and it is what the earlier runs were fighting.

The group shot and the Pip two-hander need their other references as well — each prompt
lists exactly what to attach immediately above its code block.

## The change, in one line

Each prompt's `MUST HOLD` block now opens with *bald scalp, but never a bare brow*.
That phrasing is deliberate: "bald" and "eyebrows" read as contradictory to a model, and
the earlier failures were it resolving the contradiction in the wrong direction. Naming
both halves in the same clause stops it choosing.

## Scene changes

**None.** Framing, lighting, wardrobe, camera and aspect are all unchanged from the
accepted versions. Only the brow constraint moved. Everything else about these three
images was fine and should come back the same.

## Save over the existing files

`vol1-s03.png`, `vol1-s06.png`, `vol2-s05.png` — same names, same 3:2 aspect. The alt
text on each is already written and does not change.
